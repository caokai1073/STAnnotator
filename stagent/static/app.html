A CSV (or TSV) with one row per cell: the cell id (as in the sample, e.g. the h5ad obs names or the Xenium cell_id), the cell type, and optionally a lineage that groups the types. Cells table (CSV)
      
One row per cell: cell id, region, cell type, lineage, type levels, confidence, expression label,
        marker cluster, hand-labeled, niche, Leiden cluster, UMAP 1 and 2 (when computed) and the coordinates (um).

      

    
Analysis notebook (Jupyter)
      
The code of every step with this annotation's parameters (data, placement on the image, annotation
        with its regions, priors and corrections, PCA / UMAP / Leiden, niches) and its results (tables, figures).
        It runs without this app, with the data files and common Python packages, and checks that the labels,
        clusters and niches come out the same.

      

    
Registration (CSV)
      
The affine that places the cells on the image, as used now (from the registration file,
        the agent's alignment or a correction): columns a11, a12, a21, a22, tx, ty (cell um to image pixels). It can be
        imported again under Import > Registration, or used by other tools.
