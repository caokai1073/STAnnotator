## STAnnotator 0.2.59

Spatial transcriptomics on the tissue image, from registration and cell types to regions, niches, composition and DE
genes, cell-cell communication, trajectories and comparisons across slices, with an AI agent at your side.

**This version needs macOS 14 (Sonoma) or later on a Mac.**

### What's new

**Fixes to Refine cell types**
- A Refine round could fail to start with "cannot convert float NaN to integer" on some annotations (when the rare-type
  search had taken every cell of a cluster the marker step left untyped). It starts again.
- After an annotation of all slices together, the Refine window now opens as after one slice, and **Accept**
  annotates all slices together again with the accepted edits (before, only the current slice was annotated again).
- **Refine cell types round N** opens its window at once and sums up the annotation there; the summary takes about a
  third of the time it did (a 790,000-cell CosMx section: 26 s → 8 s, most of it reading the counts the first time).
  The marker check of the Review window is faster too (18 s → 1.4 s).
- "The agent is reviewing…" is shown only while the agent works on the current round: it no longer stays from the
  round before.

**Faster marker annotation on large samples**
- The Leiden clusterings a level tries (resolutions 0.5, 1, 2 and 4, and the finer ones of the rare-type search) run
  at once in separate processes when the computer has the memory and cores for them, with the same clusters as one
  after the other. A 708,983-cell Xenium 5K lymph node: 227 s → 184 s; a 202,910-cell Xenium section: 20 s → 15 s.
  Each process needs about 1.8 GB for 700,000 cells; with less memory free the resolutions run one after the other
  as before.

**Also**
- **Unload H&E** (Data tab) is removed: it freed little memory (the image takes tens of MB of tiles; the app now hands
  memory back by itself). A sample unloaded before shows its image again, with its registration.
