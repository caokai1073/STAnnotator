## STAnnotator 0.2.63

Spatial transcriptomics on the tissue image, from registration and cell types to regions, niches, composition and DE
genes, cell-cell communication, trajectories and comparisons across slices, with an AI agent at your side.

**This version needs macOS 14 (Sonoma) or later on a Mac.**

### What's new

- **Groups of slices and of regions**: **Group** (Data tab, beside Rename) puts the slices of a project into groups, e.g. condition: UC or control, and **Group** in the Regions panel puts regions into groups, e.g. mucosa_1 and mucosa_2 in mucosa (in a project, for all its slices). Compare then compares the groups (DE genes, composition, signaling, and for slices DESeq2 with the slices of a group as replicates).
- **Image brightness and contrast**: **Adjust** (beside the **Image** box, right of the agent's buttons on the map) sets the brightness and contrast of the image shown, and for a fluorescence image (DAPI, a protein / IF channel) its display range and gamma, so dim or saturated signal can be seen; each image and channel keeps its own settings.
- **Reproduction guide for agents**: **Export** now also saves a zip for an AI agent (or a person) who repeats the analysis without the app: a step-by-step guide (input files with checksums, filter, placement, annotation with its marker list and settings, embedding, niches, every analysis you ran, how the figures are drawn), links to the code at this version, the results to check against, the data tables and colors, and optionally the notebook.
- **Genes and programs in the project overview**: Overview of the project now colors every slice by a gene (one color scale on all slices) or by a gene program scored in Compare > Programs.

### Improvements

- **Images of several channels**: a fluorescence image file with several channels (e.g. an OME-TIFF of DAPI, CD45 and PanCK) now gives one entry per channel in the **Image** box on the map, named from the file, so each channel can be shown under the cells; before, only its first channel was shown.

- **Genes and programs on a color bar**: Color by gene expression or by a program now shows each cell's value (normalized expression, or the program score) on a continuous color bar instead of bins, on one scale for all slices of a project (on the map and in the overview), so the same color means the same value on each slice. Cells where the gene is not detected, or the program is at background, are drawn under the others, so they no longer cover the cells that express it.

- The built-in brain list now separates CA1 and CA3 pyramidal neurons and has more markers for several types (e.g. endothelial cells, microglia, ependymal cells, inhibitory neurons). On a labeled mouse brain (Allen ABC MERFISH) the annotation agrees as well as before overall and better on most types; on a whole-transcriptome Stereo-seq brain fewer cells get a type their markers do not support.
- The built-in kidney list tells thin limbs from thick ascending limbs, and principal cells from connecting tubule, better. On a labeled human kidney atlas (KPMP) the annotation agrees with the atlas for 79% of the cells instead of 70%.
- Built-in lists of lung, breast, lymph node / tonsil, stomach, liver, colon and small intestine checked against labeled human single-cell atlases, with markers reordered or added where it helped: e.g. club cells in the lung, luminal progenitors in the breast, neck mucous and enteroendocrine cells in the stomach, hepatic stellate cells, and in the lymph node Tregs, NK cells and a new monocyte type.
- Built-in lists also checked on mouse data: mouse gene names added where the human ones do not exist in mouse (e.g. naive B cells and pDCs in the lymph node), a neutrophil type in the lymph node list, and alternatives for colonocytes and goblet cells on panels without the usual colon genes.
- Adding an image of exactly the size of one of the sample's images (another channel or stain of the same scan) now takes it as in that image's pixels by default, instead of asking for a registration or an alignment.
- **Discard** on Steps → Image takes images out of a sample: the H&E, the DAPI, a stain or a single channel (their files stay where they are; adding a file again brings it back). When the image the cells are placed on goes, they move onto the next image by its own registration. An image waiting for its alignment can be discarded the same way; before, it could only be aligned.
- In each Refine round the agent now looks at the tissue image before proposing (it is reminded once if it did not), and the window says when it did not.
- When the cells sit far off their nuclei over most of the tissue (a rotation or scale error of the whole alignment), the registration check and the agent's review now advise **aligning again** instead of the local registration, with one click (Align automatically, with Undo).
- Aligning an image without a registration file also tries other pixel sizes when the one stored in the image file fits badly (a wrong size in the file no longer stops it, and the result is as precise as with the right size); the agent can be given the image's pixel size.

### Fixes

- On large gene panels (some 5,000 genes) the agent's marker check and panel gene list were too long for Claude Code, which passed on only their first part; they are now about half as long with the same numbers, and the agent can check a few genes against the panel.
- When a Refine round was stopped or accepted while the agent was still working, the agent got a confusing error; it is now told what happened (and the next round's annotation, when there is one).
- Importing a Xenium output by choosing its files (not its folder) left out its DAPI image, and choosing the instrument's own DAPI afterwards ran a full alignment search (minutes on a large slide); the import now finds the DAPI next to the cells file, and the instrument's own images are placed at once.
- A Xenium output with all four morphology images (DAPI, boundary, interior RNA and protein stains) could not show them: each was refused as an incomplete image, or showed the DAPI; each now opens and shows its own stain.
- After a registration check that advised aligning again, Steps showed the image step as done; it now stays to do, with **Align again**.
- Niches of one slice computed after niches of all slices together used the project's NMF programs instead of the slice's own, so an exported notebook did not reproduce them; each now keeps its own.
- Files exported from a renamed slice or sample (cell table, notebook, registration, regions, report, figures) were still named after the name it was imported under; they now carry the new name.
- An exported notebook stopped in its annotation cell ("module 'sa.config' has no attribute 'read_settings'"); it now runs through.
- Niches could come out slightly different (about 0.1% of the cells) when computed twice on the same data, so an exported notebook did not always reproduce them; they are now computed the same way every time. Recomputing niches made in an earlier version can give somewhat different niches.
- Fixed some bugs, among them the orange **Update** button turning all white under the mouse.
