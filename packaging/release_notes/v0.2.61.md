## STAnnotator 0.2.61

Spatial transcriptomics on the tissue image, from registration and cell types to regions, niches, composition and DE
genes, cell-cell communication, trajectories and comparisons across slices, with an AI agent at your side.

**This version needs macOS 14 (Sonoma) or later on a Mac.**

### What's new

- **Intel Macs**: a build for Intel Macs, `STAnnotator_Intel.dmg` (the exact neighbor search runs on the CPU there:
  MLX, the Apple GPU path, is Apple silicon only). The app's updates pick the file for the Mac's processor by
  themselves.
- **10x Atera**: Import reads Atera output (Xenium / Atera: its `cell_feature_matrix.zarr.zip`, or the output
  folder), with its DAPI image and the H&E aligned as for Xenium. Whole-transcriptome data (Atera, Visium HD) now
  imports and annotates in about a third less memory (a 400,000-cell Atera slide: import 13 → 6 GB, annotation 15 →
  10 GB), with the same results.
- **DESeq2 charts**: the DESeq2 result has a **Dot plot** and a **Volcano** plot (every gene tested, the strongest
  named), both saved as PDF.
- **Protein / IF stains as evidence**: CosMx (PanCK, CD45, CD3...) and Xenium protein stains measured per cell now
  help the annotation (Type → Advanced → Use protein / IF stains, on by default for samples that have them): each
  type's share of stain-positive cells is learned from the annotation and every cell's stains reweigh its types.
  A stain counts only where it clearly separates types (e.g. PanCK: epithelial vs the rest); nuclear and membrane
  stains, and stains whose levels run on from type to type, are left out.
- **Spatially variable genes**: Compare → Spatial lists genes that form patches or gradients in the tissue (Moran's
  I), by default beyond what the cell types explain (e.g. the crypt base, inflamed epithelium), per slice or across
  all slices.
- **Gene program scores**: Compare → Programs scores proliferation, interferon responses, hypoxia, inflammation,
  cytotoxicity, exhaustion, EMT, fibrosis and more (or your own genes) in every cell, by group, and colors the map by
  the score. The agent can run both.
- **Composition test between conditions**: Compare → Composition over all slices, with Rows a condition, now tests
  whether each cell type (or niche) makes up a different share between the conditions, with the slices (or patients)
  as replicates (as propeller: moderated t or F, FDR), in a **Test** view with its own CSV. The agent reports it too.
- **Brain priors for the whole brain**: the brain's tissue priors now cover every type of the built-in brain list,
  not only the cortex: hippocampal CA and dentate granule layers, striatal MSNs, thalamic neurons, the cerebellar
  layers (granule cells, Purkinje cells, MLIs), the monoaminergic nuclei, ependyma and choroid plexus, and VSMCs
  beside pericytes, with the compartments to draw for a whole-brain section.
- **Updates arrive sooner**: an app that stays open checks for a new version every hour instead of every 6 hours,
  and right after the computer wakes from sleep (before, sleep paused the count, so a Mac that is only ever closed
  could wait days).

### Fixes

- Fixed some bugs and made small improvements, among them the Type tab freezing when a method other than marker
  genes was chosen before any annotation was open, **Last result** now also for analyses the agent ran (e.g. a
  trajectory) and on every slice for analyses of all slices, tidier result windows (the analysis named on top, its
  views in the middle) and Compare choices, and the cells fully opaque by default.
