## STAnnotator 0.2.62

Spatial transcriptomics on the tissue image, from registration and cell types to regions, niches, composition and DE
genes, cell-cell communication, trajectories and comparisons across slices, with an AI agent at your side.

**This version needs macOS 14 (Sonoma) or later on a Mac.**

### What's new

- **Intel Macs**: a build for Intel Macs, `STAnnotator_Intel.dmg` (the exact neighbor search runs on the CPU there:
  MLX, the Apple GPU path, is Apple silicon only). The app's updates pick the file for the Mac's processor by
  themselves.
- **10x Atera**: Import reads Atera output (Xenium / Atera: its `cell_feature_matrix.zarr.zip`, or the output
  folder), with its DAPI image and the H&E aligned as for Xenium. Whole-transcriptome data (Atera, Visium HD) now
  imports and annotates in about a third less memory (a 400,000-cell Atera slide: import 13 → 6 GB, annotation 15 →
  10 GB), with the same results.
- **Align automatically**: an H&E without a registration file can now be aligned by the app alone, without the
  agent (Steps → Image → Align, or the "not aligned yet" notice): the best placements are refined and checked
  over the whole tissue, and the one whose cells sit on their nuclei is applied, then shown with Undo (about a
  minute or two; on a 400,000-cell Atera kidney slide, within half a micrometer of 10x's own alignment). Align
  with Agent remains for slides it cannot settle (several sections, a symmetric tissue). The Steps' second step is
  now **Image**: Import (the image of a sample imported without one), Align, then Check.
- **Several images per sample**: the **Image** box on the map switches the image under the cells between the H&E,
  the DAPI and protein / IF stains, each placed by its own registration (the cells and regions stay where they
  are). Xenium and Atera samples list the instrument's DAPI and morphology stains by themselves; the DAPI shown
  before an H&E is aligned stays in the list; Steps → Image → Add adds another image (with its registration file,
  or in the same pixels as one of the sample's images).
- **Embed and Niche before annotating**: PCA / UMAP / Leiden and niches of NMF programs run on the expression alone,
  so they no longer wait for an annotation (one slice or all slices together, and the agent's niches too); the UMAP
  shows the cell types once the sample is annotated, and the niches come along into its first annotation. Compare,
  Signal and Trajectory show an **Annotate first** button until then.
- **Faster annotation on many cores**: the PCA's sums run on every core (each in a fixed order, so the result is the
  same on any computer), and whole-transcriptome levels pick their genes much faster: a 400,000-cell Atera slide
  365 → 285 s, a 350,000-cell Xenium section 78 → 59 s on a 20-thread server, with the same cell types.
- **DESeq2 charts**: the DESeq2 result has a **Dot plot** and a **Volcano** plot (every gene tested, the strongest
  named), both saved as PDF.
- **Protein / IF stains as evidence**: CosMx (PanCK, CD45, CD3...) and Xenium protein stains measured per cell now
  help the annotation (Type → Advanced → Use protein / IF stains, on by default for samples that have them): each
  type's share of stain-positive cells is learned from the annotation and every cell's stains reweigh its types.
  A stain counts only where it clearly separates types (e.g. PanCK: epithelial vs the rest); nuclear and membrane
  stains, and stains whose levels run on from type to type, are left out.
- **Spatially variable genes**: Compare → Spatial lists genes that form patches or gradients in the tissue (Moran's
  I), by default beyond what the cell types explain (e.g. the crypt base, inflamed epithelium), per slice or across
  all slices.
- **Gene program scores**: Compare → Programs scores proliferation, interferon responses, hypoxia, inflammation,
  cytotoxicity, exhaustion, EMT, fibrosis and more (or your own genes) in every cell, by group, and colors the map by
  the score. The agent can run both.
- **Composition test between conditions**: Compare → Composition over all slices, with Rows a condition, now tests
  whether each cell type (or niche) makes up a different share between the conditions, with the slices (or patients)
  as replicates (as propeller: moderated t or F, FDR), in a **Test** view with its own CSV. The agent reports it too.
- **Brain priors for the whole brain**: the brain's tissue priors now cover every type of the built-in brain list,
  not only the cortex: hippocampal CA and dentate granule layers, striatal MSNs, thalamic neurons, the cerebellar
  layers (granule cells, Purkinje cells, MLIs), the monoaminergic nuclei, ependyma and choroid plexus, and VSMCs
  beside pericytes, with the compartments to draw for a whole-brain section.
- **Updates arrive sooner**: an app that stays open checks for a new version every hour instead of every 6 hours,
  and right after the computer wakes from sleep (before, sleep paused the count, so a Mac that is only ever closed
  could wait days). While a new version waits, an **Update** button stays at the top of the toolbar.

### Fixes

- An H&E still being copied, cut short, damaged or not a TIFF no longer leaves an empty map or a failing sample: the
  app says why at once, and the Image step offers **Refresh** for when the file is complete.
- An annotation started while an automatic alignment ran on the same sample could freeze the app (OpenBLAS threads
  waiting on each other): the two no longer overlap, Annotate and Filter wait (greyed) while the cells are being
  placed, also when the alignment was started in another window, and an annotation left half made by an app that
  was ended goes to the trash at the next start.
- Cells placed by a registration file (Import, Steps → Image) are checked against the nuclei at once; after an
  alignment whose check found areas off their nuclei, its window (with Do local registration) opens by itself.
- Fixed some bugs and made small improvements, among them the Type tab freezing when a method other than marker
  genes was chosen before any annotation was open; **Last result** also for analyses the agent ran (e.g. a trajectory)
  and on every slice for analyses of all slices; tidier result windows and Compare choices; the cells fully opaque by
  default; **Dot size** also when the map is zoomed far out; a progress bar while an accepted change of the agent is
  applied, and in Filter on a line of its own; bug and usage reports list the analyses run in the app (kind,
  settings and time, not results); About no longer has a Daily count switch (the count holds only a random id, the
  version and the system), and the toolbar no longer shows the data folder (it is in About); the in-app help (How
  to use, Agent, Methods) covers all of the above.
