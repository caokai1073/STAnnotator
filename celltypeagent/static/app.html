A CSV (or TSV) with one row per cell: the cell id (as in the sample, e.g. the h5ad obs names or the Xenium cell_id), the cell type, and optionally a lineage that groups the types. Its labels become the annotation; cells not in the file are Unassigned. A CSV exported from this app can be loaded back.
